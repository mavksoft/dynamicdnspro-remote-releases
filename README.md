# DDNSPro Remote — releases

Binarios firmados de **DynamicDNSPro Remote** (visor nativo Flutter):

- `DDNSProRemote-macOS-X.Y.Z.dmg` — instalador macOS (Developer ID + notarizado)
- `DDNSProRemote-macOS-X.Y.Z.zip` — update Sparkle (firma EdDSA)
- `visor_macos.json` — manifiesto de versión (lo lee remote.dynamicdnspro.com)
- `visor_macos_appcast.xml` — feed Sparkle

Código fuente: [mavksoft/DynamicDNSPro-Remote](https://github.com/mavksoft/DynamicDNSPro-Remote)
